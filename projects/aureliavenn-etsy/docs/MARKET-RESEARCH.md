# Piackutatás — Etsy bestseller tanulságok (2026-10-03)

## Digitális
- **Képsor = feature-katalógus:** ~10–15 kép, mindegyik 1 funkció + 1 soros haszon + eszköz-mockup + 2–3 jelvény.
- **Egységes paletta** a képsoron (pl. zsálya + púder + krém).
- **„Is this right for you?” kép** a kifogásokra; **kompatibilitás-kép** (Excel + Google Sheets, PC/Mac/telefon).
- **Betanítás a termék része** (útmutató, videó) — fő dicséret: „könnyű beállítani”.
- „Updated version” jelvény, vevői idézetek a képeken (ha már vannak).
- **Keresztértékesítés:** színváltozatok, csomag „X% vs külön”.
- **Az eredményt mutasd, ne a fájlt** (kitöltött oldal, lépésről lépésre).
- Bónuszok emelik az értéket.

## POD (ősz / macska / karácsony)
1. **Comfort Colors 1717** a domináns póló, a márkanév a cím elején; ~$35 listaár.
2. **Szójáték + illusztráció** nyer („We knead em, you need em”, „I like fall a latte”). A „Pumpkin spice? I prefer mice” ebbe a sávba esik.
3. Két nyerő stílus: vintage, szitanyomás-hatás 2–3 színnel; vagy részletes, cuki akvarell cica sötét pólón. Fekete macska a leggyakoribb.
4. Első kép: rövid videó vagy flat lay; modellkép; méret-táblázat.
5. **Személyre szabás** (macskanév, fajtaválasztó) → magasabb ár, kevesebb verseny.
6. Értékelések témái: szállítás, méret, minőség, szín. Panasz: méretezés → „true to size, size up for oversized”.
7. Mintafájl (PNG, bögre-wrap) is eladható ~€2–3-ért.
