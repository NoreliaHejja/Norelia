# Facebook-csoportposztok (német)

Szabály: sok csoportban tilos a link → a link az első kommentbe megy. Előtte olvasd el a csoportszabályokat, és 1–2 napig kommentelj hasznosan.
Sorrend: hétfő 1. poszt (2 csoport), szerda 2. poszt, péntek 3. poszt (Gründer-csoportok).

> A számok a web-rechner példaértékeire épülnek (15 € bér, 28 % LNK, 20 % kiesés → ~31 €/h).

## 1. poszt – kérdés (beszélgetést indít)

```
Kurze Frage an alle Reinigungsfirmen hier: Mit welchem Stundensatz kalkuliert ihr aktuell?

Ich habe nachgerechnet: Bei 15 € Stundenlohn, 28 % Lohnnebenkosten und 20 % Ausfallzeit (Urlaub, Krankheit) liegt der Mindestsatz schon bei gut 31 €/h, bevor überhaupt ein Auftrag schwierig wird.

Viele Angebote, die ich sehe, liegen bei 24–27 €. Wie geht das auf? Übersehe ich etwas?

Ich habe mir dafür einen kostenlosen Rechner gebaut. Wer will, kann seine eigenen Zahlen eintragen (Link im ersten Kommentar).
```

## 2. poszt – hibalista (hasznos tartalom)

```
3 Rechenfehler, die ich bei Reinigungsfirmen immer wieder sehe:

1. Urlaub und Krankheit fehlen im Stundensatz. Bei ca. 20 % Ausfall arbeitet das Team jeden fünften Tag ohne Deckung.
2. Leistungswerte werden pauschal angesetzt. Ein Büro mit Teppich braucht mehr Zeit als ein leerer Flur.
3. Gemeinkosten werden vergessen: Fahrzeug, Versicherung, Buchhaltung und das eigene Gehalt gehören in jede verkaufte Stunde.

Welchen Fehler habt ihr am Anfang gemacht?

Kostenloser Stundensatz-Rechner zum Nachprüfen: Link im Kommentar.
```

## 3. poszt – Gründer-csoportokba

```
Für alle, die gerade eine Reinigungsfirma gründen:

Rechnet euren Stundensatz, BEVOR ihr das erste Angebot schreibt. Der häufigste Fehler: Stundenlohn × 2 und fertig. Das reicht oft nicht, sobald Fahrzeug, Versicherung und Ausfallzeiten dazukommen.

Ich habe einen kostenlosen Rechner gemacht, ohne Anmeldung, in einer Minute ausgefüllt. Link im ersten Kommentar. Feedback ist willkommen, ich baue gerade Vorlagen für Kalkulation und Angebote.
```

## Török nyelvű poszt (opcionális teszt)

Még nincs megírva. Cél: németországi török takarítócég-tulajdonosok csoportjai („Almanya'da temizlik firmaları” típusúak), link a német oldalra. Ha innen jön a legtöbb eladás → török oldalt érdemes fontolni.
