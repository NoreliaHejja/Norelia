1. Érdeklődés → monday „PK Tech Ugyfelek” (Leads csoport)
2. Helyszíni felmérés: **minden ajánlat előtt kötelező** → műszaki vezető
3. Ajánlat (`pk-tech-dokumentumok` skill, sorszám: 2026-NNN) → Nóra jóváhagyja → kiküldés
4. Ütemezés: munkatársak + alkalmi munkások (HR)
5. Kivitelezés → jegyzőkönyv, teljesítésigazolás (TIG), fotók Drive-on (`pk-tech-munka-dokumentacio` skill)
6. Számla: **Nóra állítja ki** (Számlázz.hu / Billingo) → kintlévőség-figyelés (pénzügy)
7. Utánkövetés: Google-értékelés kérése, következő időszakos munka dátuma, referencia-engedély (sales)
